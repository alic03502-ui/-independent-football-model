# ⚽ Independent Football Value Model

A standalone football prediction and bookmaker value model built with Python and Streamlit.

## Features

- Expected goals
- xG + actual-goal blending
- Home advantage
- Away adjustment
- Recent form
- League position
- H2H scoring
- Poisson probability model
- 1X2 probabilities
- Over/Under 1.5
- Over/Under 2.5
- Over/Under 3.5
- BTTS
- Team goals
- Most likely scorelines
- Fair odds
- Bookmaker comparison
- Edge
- Expected value
- Value detection

## Deployment

The application entry point is:

`app.py`

Dependencies are listed in:

`requirements.txt`

Deploy `app.py` using Streamlit Community Cloud.
